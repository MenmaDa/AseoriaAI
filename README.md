# Plan de Trabajo del Proyecto

## Objetivo
Desarrollar un proyecto funcional dividido en 4 avances semanales, mostrando progreso continuo y organizado.

---

## Cronograma

### Semana 1: Planeación y estructura
- [ ] Crear repositorio en GitHub
- [ ] Definir el objetivo del proyecto
- [ ] Crear archivo README.md
- [ ] Subir primer notebook o código base
- [ ] Organizar carpetas del proyecto

Entregable:
- Estructura inicial del proyecto funcionando

---

### Semana 2: Desarrollo inicial
- [ ] Implementar funcionalidad principal
- [ ] Subir avances del código
- [ ] Documentar el proceso en el README
- [ ] Realizar primeros tests básicos

Entregable:
- Primera versión funcional del proyecto

---

### Semana 3: Mejora y pruebas
- [ ] Optimizar el código
- [ ] Corregir errores detectados
- [ ] Agregar validaciones o pruebas
- [ ] Mejorar organización del código

Entregable:
- Versión mejorada y más estable

---

### Semana 4: Entrega final
- [ ] Limpieza final del código
- [ ] Documentación completa
- [ ] Agregar conclusiones/resultados
- [ ] Preparar presentación del proyecto

Entregable:
- Proyecto final listo para evaluación
